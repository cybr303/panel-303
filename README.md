# 303

Personal life panel: today, habits and streaks, money and yearly goals. Installable on the iPhone from Safari (Share → Add to Home Screen).

- `web/` — the app (Vite + TypeScript PWA), published to GitHub Pages.
- `worker/` — Cloudflare Worker that talks to Notion and keeps every secret.

No personal data, tokens or keys live in this repository. See `CLAUDE.md` for how the project works.
